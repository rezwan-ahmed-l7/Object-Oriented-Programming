## Overview

This repository documents my practice with Object-Oriented Programming (OOP) in C++ as part of my Computer Science and Engineering studies. It contains focused examples for learning core OOP concepts, understanding how they work in code, and practicing problem-solving.

The numbered topic folders inside `OOP Codes` follow a learning sequence from introductory concepts to classes, inheritance, polymorphism, memory management, templates, file handling, and design principles. Practical examples and practice assessments are maintained separately.

## Key Concepts

- **Classes and objects:** defining classes, creating objects, and working with member functions
- **Constructors and object copying:** initializing objects, constructor overloading, copy constructors, and object lifetime
- **Encapsulation and access control:** protecting data and controlling access to class members
- **Inheritance:** reusing class behavior through different inheritance relationships
- **Polymorphism and abstraction:** function overriding, virtual functions, abstract classes, and pure virtual functions
- **Operator overloading:** defining operators for user-defined types
- **Dynamic memory and pointers:** working with pointers and dynamically allocated objects
- **Templates and STL:** writing reusable code and using standard library facilities
- **Exception and file handling:** handling errors and performing file input/output
- **Design principles:** exploring maintainable OOP structure and introductory design patterns

## Getting Started

### Requirements

- A C++ compiler such as [G++](https://gcc.gnu.org/)
- A code editor or IDE; VS Code is one option

### Compile and Run

Open a terminal at the repository root. For example, compile an example from the current folder structure:

```bash
g++ -std=c++17 "OOP Codes/02. Classes and Objects/02_Array_of_Objects.cpp" -o example
```

Run on Linux or macOS:

```bash
./example
```

On Windows PowerShell:

```powershell
.\example.exe
```

Replace the source path and output name with the program you want to run. Most source files are independent examples, so compile one `.cpp` file at a time.

## How to Use This Repository

1. Start with **Introduction to OOP** and **Classes and Objects**.
2. Continue through **Encapsulation and Access Control**, **Constructors and Destructors**, and **Copy Constructors and Object Copying**.
3. Study **Friend Functions and Classes**, **Inheritance**, **Polymorphism**, and **Abstraction**.
4. Explore **Advanced Inheritance** and **Operator Overloading**.
5. Continue with **Pointers and Dynamic Memory**, **Templates**, **Exception Handling**, and **File Handling**.
6. Explore **Namespaces and C++ Utilities**, the **Standard Template Library (STL)**, and **OOP Design Principles and Patterns**.
7. Use **Practical Examples** to see concepts applied in larger programs.
8. Use **Practice Assessments** to review concepts and strengthen problem-solving skills.
